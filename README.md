# Northbank Cognitive Systems Lab — Website

Jekyll source for the lab's public website.

## Repository layout

- `_publications/` — one Markdown file per paper; the YAML front matter controls the rendered entry.
- `_data/` — structured site data, including the conference travel plan.
- `emails_github_rail_12306_3440_k3m9x2_code_archive/` — the lab's code archive, one project directory per paper. Each project's README states its release status.
